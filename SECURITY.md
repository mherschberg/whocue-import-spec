# Security Policy

This repository defines the public WhoCue import contract. We take the integrity
of that contract seriously.

## Reporting a problem

Please **do not** open a public GitHub issue for security-sensitive reports.
Instead, report privately using GitHub's **private vulnerability reporting**
("Report a vulnerability" under this repository's **Security** tab).

Where possible, include:

- a description of the issue and its impact,
- steps to reproduce, and
- scrubbed example paths (for example `$.people[0].image.url`) rather than real
  data.

Do **not** include real attendee lists, private notes, contact details, or other
personal data in a report. Use synthetic values that demonstrate the issue.
