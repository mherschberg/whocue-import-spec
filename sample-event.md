# Try a sample event in WhoCue

**[Download the WhoCue sample ZIP](https://github.com/mherschberg/whocue-import-spec/raw/bd5b2f780419a001477e7c96321ec32980c6c669/examples/valid/realistic-demo.zip)**

Try *Metro Product Forum 2027* with three fictional people and their photos. This prebuilt demo event shows what your LLM’s output looks like in WhoCue.

1. Download the file on your phone and keep it zipped.
2. In WhoCue, go to **Events → Import event** and select the ZIP. If your file manager offers **Open With → WhoCue**, you can use that too.
3. Review the preview and confirm the import.
